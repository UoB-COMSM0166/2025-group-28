# Repo Management #


## Branches ##

In most cases, a new branches should be created to represent the work being completed on a certain feauture/area by an individual. The branch name should be structured as follows:

  sprint number + quick description e.g. epic name, e.g s1_game_class_enhancements 

### Steps:
  - **1** - Create a branch from main (either in via GUI or command line)
  - **2** - Commit work to new branch, test code on new branch
  - **3** - When ready, create a pull request to main branch
  - **4** - Add a description detailing what you are changing and which epics/stories it relates to.
  - **5** - Tell another team member to check and merge pull request
  - **6** - Delete branch if no more work is being done on the issue.
